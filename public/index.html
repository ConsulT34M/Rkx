HOW IT WORKS

상담 진행 안내

RKX에서 신청한 상담은 아래 흐름으로 진행됩니다.

01

가입 정보 입력

이름·이메일·비밀번호와 필수 동의 항목을 입력합니다.

02

본인확인·계정 생성

샘플 인물로 휴대폰·가상 증표·얼굴 이미지 단계를 완료하면 계정이 생성됩니다. 실제 신원 확인이 아닌 실습용 흐름입니다.

03

상담 접수

상담·전화 요청을 접수합니다. 접수번호와 필요한 최소 항목을 말결 상담 채널로 전달합니다.

04

상담 이어가기

채팅과 접수 상태를 확인하고, 추가 문의는 새 상담으로 남길 수 있습니다.

서비스 목적

RKX는 디지털 자산 시세 정보와 상담 접수 기능을 제공합니다. 이 서비스에서 자산 거래, 투자 권유, 자산 수탁은 제공하지 않습니다.

계정과 이용

가입 정보를 입력하고 필수 항목에 동의한 뒤 샘플 인물의 모의 본인확인 흐름을 모두 마치면 계정이 생성되며 로그인할 수 있습니다. 실제 신원 확인으로 사용할 수 없습니다. 다른 사람의 계정을 사용하거나 상담 기능을 남용해서는 안 됩니다.

상담 연결

상담 접수·채팅·전화 상담은 말결 연계 절차에 따라 진행됩니다. 실제 운영 조건과 연락처는 수탁사 계약 확정 후 고지합니다.

PRIVACY

개인정보처리방침

서비스 운영을 위한 정책 초안입니다. 실제 운영 전 담당자·보유기간·수탁 계약 내용을 확정해야 합니다.

RKX 개인정보처리방침 (운영 전 검토 초안)

1. 처리 목적과 항목

가입 신청 단계에서 이름, 이메일, 비밀번호 해시값과 동의 항목을 임시 보관합니다. 연락처는 본인확인 휴대폰 단계에서 입력받으며, 모든 실습용 본인확인 단계를 마친 뒤 계정에 저장합니다. 로그인 시 본인확인 상태와 실패 횟수를 처리합니다. 로그인 실패 2회부터 이미지 CAPTCHA로 자동입력을 확인합니다. 상담 접수·채팅: 고객이 입력한 상담 내용, 희망 연락 시간, 녹취 요청 동의 여부를 처리합니다. 말결 테스트 화면에서는 모의 녹취 파일과 재생·파기 이력을 처리할 수 있습니다. 모의 본인확인에서는 가상 성명·번호·발급일자와 신분증·얼굴 이미지를 제출합니다. RKX는 촬영 이미지를 DB에 저장하지 않고 단계별 판정에만 사용합니다. IJ-info 연동을 설정하면 촬영 이미지가 해당 테스트 서비스로 전송됩니다. 실물 증표나 실제 인물 사진을 입력하지 마세요.

2. 보유 및 이용 기간

계정·상담 데이터의 구체적인 보유기간은 운영 정책과 관련 법령 검토 후 확정하여 고지합니다. 모의 녹취는 설정된 보관기간이 지나면 파일을 삭제하고 이력을 남깁니다.

3. 처리 위탁

본인확인 실습 연계 대상: (주)인증정보평가(IJ-info). 상담 접수 연계 예정 수탁사: (주)말결(MK). 실제 전송 항목, 위탁 업무, 보유기간, 재위탁 여부는 계약과 연동 사양을 확정한 뒤 게시합니다.

4. 이용자의 권리

이용자는 개인정보 열람·정정·삭제·처리정지를 요청할 수 있습니다. 접수 창구와 처리 절차는 운영 개시 전 명시합니다.

5. 안전성 확보 조치

비밀번호 해시 저장, 고객·관리자·수탁사 권한 분리, 2회 실패 후 CAPTCHA, 로그인 세션 보호와 관리자 조회·다운로드 기록을 적용합니다. 운영 전 HTTPS와 보관·파기 절차를 구성합니다.

6. 연락처 및 시행일

개인정보 보호책임자, 담당 부서, 문의처, 시행일은 운영 주체가 확정 후 게시합니다.
